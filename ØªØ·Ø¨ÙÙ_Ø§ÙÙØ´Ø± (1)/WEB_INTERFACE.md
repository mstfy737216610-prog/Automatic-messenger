# دليل الواجهة الويب

الواجهة عربية RTL وتعمل على الهاتف وسطح المكتب. شريط الحالة العلوي يوضح دائمًا هل النظام في **وضع الاختبار** أم أن النشر الفعلي مفعّل. البيانات محلية في الجهاز الذي يشغّل الخادم.

## الرئيسية `/`

- مقاييس المنشورات بانتظار المراجعة، الجاهزة، المنشورة، والحالات التي تحتاج تدخلًا.
- عدد المهام النشطة ومسار العمل: مراقبة ← فلترة ← مراجعة ← تجهيز ونشر.
- **فحص الحسابات النشطة:** يضيف مهمة فحص لكل حساب مفعّل؛ لا يتجاوز الطابور ولا ينشر مباشرة.
- حالة الجلسة وعدد المصادر لكل حساب، وآخر الأحداث والمنشورات.

## الحسابات `/accounts`

### إنشاء حساب وتعديله

الحساب هنا هو **وجهة النشر**، وله اسم داخلي ومنصة واسم مستخدم. الحقول تشمل:

- رقم الهاتف البديل، ولا يُستخدم برمجيًا إلا للمساعدة الطلابية/القروبات وفق قرار الفلترة.
- بروكسي ثابت، وفترة الفحص، وحدود التأخير.
- وضع الصور: إعادة بناء النص على القالب، أو الإبقاء على الصورة وإضافة الشعار.
- ألوان الخلفية والنص واللون المميز، وOCR واستبدال معرف المصدر.
- رابط محادثة Telegram Web عند اختيار Telegram.
- تشغيل المراقبة، واشتراط المراجعة، والسماح بالنشر التلقائي عالي الثقة.

اسم المنصة لا يتغير بعد إنشاء الحساب حتى لا تختلط الجلسة والمسارات بمنصة أخرى. أنشئ حسابًا جديدًا إذا أردت منصة مختلفة.

### الجلسة والبروكسي

- **استيراد Cookies:** يقبل ملف Playwright storage state أو قائمة Cookies JSON.
- **فحص الجلسة:** يفتح صفحة المنصة ويتحقق من مؤشرات الدخول المعرّفة في `selectors.yaml`.
- **تعيين تلقائي:** يختار بروكسي غير مستخدم من `proxies.txt` ويثبته للحساب.
- الواجهة تعرض البروكسي مقنّعًا ولا تعيد كلمة المرور.

### الهوية والمصادر والذاكرة

- **رفع الشعار** و**رفع خلفية القالب** بصيغ PNG/JPG/WebP، بحد أقصى 12MB للملف.
- **إنشاء معاينة:** يولّد صورة عربية فعلية بالقالب والشعار الحاليين.
- إضافة مصادر X وTikTok وInstagram، وتفعيلها أو تعطيلها أو حذفها.
- **فحص الآن:** يضيف فحص هذا الحساب إلى الطابور.
- **تحليل النمط:** يبني ملف اللهجة والموضوعات من عينات السجل عبر النموذج؛ يحتاج منشورات ومفتاح AI صالحًا.
- **حذف الحساب:** ينشئ أرشيف أمان مضغوطًا أولًا، ثم يحذف الحساب وسجلاته وجلسته. لا يشمل أرشيف الحذف الوسائط افتراضيًا.

## المراجعة `/review`

- تصفية حسب الحالة والحساب: بانتظار المراجعة، جاهز، منشور، يحتاج تأكيدًا، متجاهل/مرفوض، أو الكل.
- عرض قرار AI وسببه ونسبة الثقة، والنص الأصلي، والنص النهائي القابل للتعديل.
- مقارنة الوسائط الأصلية والمعالجة، وتشغيل الفيديو محليًا.
- **اعتماد وتجهيز:** يعالج الوسائط إذا لزم ويضيف مهمة نشر واحدة. في وضع الاختبار تكون النتيجة «جاهز» دون إرسال.
- **رفض وتعلّم:** سبب الرفض إلزامي، ويُحفظ كتغذية راجعة تدخل في سياق القرارات اللاحقة.
- **إعادة الفلترة:** يعيد المنشور إلى طابور المعالجة، ولا يتاح أثناء النشر أو بعد تأكيده أو عند غموض نتيجته.
- عند `publish_unknown` لا تظهر أزرار إعادة النشر. افتح المنصة وتحقق، ثم اختر **تأكد نشره** أو **لم يُنشر**.

## المساعد `/assistant`

- إرسال تعليمة عامة لكل الحسابات أو خاصة بحساب واحد.
- حفظ التعليمة في `instructions` وعرضها في سجل الشات؛ لا يُجرى Fine-tuning.
- تعديل `base_url` والنموذج ومهلة الاستجابة. المفتاح نفسه لا يظهر ولا يُعدّل من الواجهة؛ غيّره في `.env`.
- **جلب النماذج** و**اختبار الرد** باستخدام طلب JSON صغير. اختبار `/models` وحده لا يكفي للحكم على صلاحية المحادثة.
- عند فشل AI يبقى المنشور للمراجعة، ولا يتحول الخطأ إلى قرار نشر أو تجاهل.

## النشاط `/activity`

سجل محلي للأحداث مع تصفية حسب الحساب والمستوى. يساعد في تشخيص المصدر أو الجلسة أو المعالجة. لا يفترض أن يحتوي مفتاح AI أو كلمات مرور البروكسي. مدة الاحتفاظ الافتراضية 90 يومًا.

## الإعدادات `/settings`

- صحة SQLite وChromium وFFmpeg وTesseract وحاجز النشر.
- قائمة البروكسيات المقنّعة والحساب المرتبط بكل عنوان.
- **إنشاء نسخة احتياطية** ثم تنزيلها كملف `tar.gz`.
- **تنظيف ما تجاوز مدة الاحتفاظ** للسجلات والوسائط القديمة، مع بقاء بصمات منع التكرار.

## الوصول عبر الشبكة

الافتراضي `HOST=127.0.0.1` ولا يفتح الواجهة للأجهزة الأخرى. إذا احتجت الوصول من جهاز آخر، اضبط أولًا:

```dotenv
WEB_USERNAME=اسم_قوي
WEB_PASSWORD=كلمة_مرور_طويلة_وفريدة
HOST=0.0.0.0
```

استخدم شبكة موثوقة فقط. Basic Auth ليس بديلًا عن VPN أو HTTPS عند الشبكات غير الموثوقة، ولا تفتح المنفذ على الإنترنت مباشرة.

## حالات المنشور الأساسية

| الحالة | المعنى |
|---|---|
| `new` / `filtering` | اكتُشف أو يمر بالفلترة |
| `pending_review` | ينتظر قرارك؛ يشمل فشل AI الآمن |
| `ignored` / `rejected` | استبعده النظام أو رفضته أنت |
| `queued` / `publishing` | في طابور التجهيز أو مسار النشر |
| `ready` | اكتمل التجهيز في وضع الاختبار ولم يُرسل |
| `published` | ظهر تأكيد نجاح موثوق أو أكدته يدويًا |
| `publish_unknown` | النتيجة غامضة؛ تحقق يدويًا قبل أي إجراء |
| `failed` | فشل معروف يحتاج تشخيصًا |
