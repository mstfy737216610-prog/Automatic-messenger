# دليل الإعدادات

## ملف البيئة `.env`

انسخ `.env.example` إلى `.env` ولا تشارك الملف. الأسرار تبقى في البيئة ولا تُحفظ في SQLite أو النسخ الاحتياطية.

| المتغير | الافتراضي | الغرض |
|---|---:|---|
| `AI_API_KEY` | فارغ | مفتاح المزوّد؛ اتركه فارغًا حتى تضع مفتاحك |
| `AI_BASE_URL` | `https://api.hcnsec.cn/v1` | أساس OpenAI-compatible دون `/models` أو `/chat/completions` |
| `AI_MODEL` | `auto` | النموذج المطلوب |
| `AI_TIMEOUT_SECONDS` | `60` | مهلة الطلب، من 5 إلى 300 عبر الواجهة |
| `AI_MAX_RETRIES` | `2` | إعادة محاولات الأخطاء المؤقتة فقط |
| `HOST` | `127.0.0.1` | عنوان الاستماع |
| `PORT` | `8000` | منفذ الواجهة وAPI |
| `DATA_DIR` | `./data` | قاعدة البيانات والجلسات والوسائط والنسخ |
| `CHROMIUM_PATH` | اكتشاف تلقائي | مسار Chromium التنفيذي عند الحاجة |
| `PLAYWRIGHT_HEADLESS` | `true` | تشغيل المتصفح بلا واجهة مرئية |
| `CHROMIUM_NO_SANDBOX` | `true` | مطلوب غالبًا في Termux/الحاويات؛ قيّد الوصول للجهاز |
| `DRY_RUN` | `true` | يجهّز دون إرسال عندما يكون `true` |
| `PUBLISHING_ENABLED` | `false` | حاجز إضافي مستقل للنشر |
| `SCHEDULER_ENABLED` | `true` | جدولة الحسابات المفعّلة والتنظيف |
| `MAX_DOWNLOAD_MB` | `250` | حد تنزيل الوسائط |
| `MEDIA_RETENTION_DAYS` | `90` | عمر الوسائط قبل التنظيف |
| `LOG_RETENTION_DAYS` | `90` | عمر سجلات المنشورات والأحداث قبل التنظيف |
| `AUTO_CLEANUP` | `true` | إضافة التنظيف الدوري للطابور |
| `WEB_USERNAME` / `WEB_PASSWORD` | فارغ | Basic Auth عندما تكون القيمتان موجودتين |

بعد تعديل `.env` أعد تشغيل `bash start.sh`. إعدادات عنوان المزوّد والنموذج والمهلة الموجودة في صفحة المساعد تُحفظ في SQLite وتتقدم على قيم البيئة لهذه الحقول الثلاثة، بينما المفتاح يبقى في البيئة فقط.

## إعدادات الحساب الأساسية

تُحفظ لكل حساب بصورة مستقلة:

- `monitor_interval_sec`: الفاصل بين الفحوصات، من 60 ثانية إلى 86400.
- `min_delay_sec` و`max_delay_sec`: تأخير عشوائي واحد قبل النشر الفعلي، وليس قبل وضع الاختبار.
- `review_required`: المراجعة البشرية مطلوبة افتراضيًا.
- `auto_publish`: لا يعمل إلا مع `review_required=false` وقرار `publish` وثقة لا تقل عن `auto_confidence`.
- `phone_replacement`: رقمك البديل. الاستبدال برمجي حتمي بعد قرار AI، وليس طلبًا للنموذج.
- `settings.auto_confidence`: الافتراضي `0.88`.
- `settings.replace_username`: استبدال `@معرف_المصدر` بمعرف حسابك في النص النهائي.
- `settings.ocr_images`: استخراج نص أول صورة واستخدامه في الفلترة وإعادة البناء.
- `settings.telegram_target_url`: رابط محادثة Telegram Web المطلوبة للنشر.

## قالب الصورة

مثال كتلة داخل `settings` للحساب:

```json
{
  "template": {
    "mode": "rebuild",
    "width": 1080,
    "height": 1350,
    "background": "#f4f6f2",
    "surface": "#fcfdf9",
    "text": "#18201c",
    "muted": "#53615a",
    "accent": "#008f6d",
    "font_size": 62,
    "margin": 84,
    "logo_opacity": 0.09,
    "watermark_opacity": 0.82,
    "source_attribution": false,
    "redactions": [
      {"x": 0.08, "y": 0.12, "w": 0.42, "h": 0.08}
    ],
    "video_delogo": [
      {"x": 24, "y": 24, "w": 180, "h": 72}
    ],
    "video_color_tweak": false
  }
}
```

- `mode=rebuild`: يعيد بناء النص على القالب إذا وُجد نص؛ وإلا يحافظ على الصورة ويضيف الشعار.
- `mode=overlay`: يحافظ على الصورة الأصلية، ويطبق التعتيم والشعار.
- `redactions`: مناطق تعتيم الصورة بنسب من 0 إلى 1 بالنسبة لعرض/ارتفاع الصورة. مثال: `x=0.1` يعني بدء المنطقة عند 10٪ من العرض.
- `video_delogo`: مناطق **بالبكسل** داخل الفيديو الأصلي، بالمفاتيح `x,y,w,h` كما يتطلب مرشح FFmpeg `delogo`.
- `video_color_tweak`: تعديل بسيط فقط للتشبع والتباين، وليس محاولة لإخفاء مصدر المحتوى.
- `template_path` و`logo_path`: يضبطهما رفع الأصول من الواجهة؛ لا تعدّلهما يدويًا إلا إذا كنت تعرف المسارات النسبية داخل `data/`.

> عند استخدام `PATCH /api/accounts/{id}` تُستبدل كتلة `settings` كاملة. اقرأ الإعدادات الحالية أولًا وادمج تغييراتك معها حتى لا تحذف مسارات الشعار أو إعدادات أخرى. الواجهة تحفظ الإعدادات الأساسية بهذه الطريقة تلقائيًا.

## ملف `proxies.txt`

سطر واحد لكل عنوان، والأسطر التي تبدأ بـ`#` تعليقات. التعيين ثابت لكل حساب. راجع [PROXIES.md](PROXIES.md).

## ملف `config/selectors.yaml`

يفصل محددات القراءة ومسارات النشر عن الكود. يمكن تعديله دون تغيير Python، لكن أي تعديل يحتاج اختبارًا في وضع عدم النشر أولًا. راجع [SELECTORS.md](SELECTORS.md).

## الاحتفاظ والنسخ

- التنظيف الافتراضي بعد 90 يومًا للسجلات والوسائط.
- جدول `dedup` لا يُحذف مع السجلات القديمة، لذلك لا يؤدي التنظيف إلى إعادة نشر محتوى معروف.
- النسخة الاحتياطية تستبعد `AI_API_KEY` و`.env` والوسائط المنزلة وملفات `cookies-*.txt` المؤقتة.
- الجلسات داخل النسخة حساسة؛ احمِ ملفات النسخ مثلما تحمي كلمات المرور.
